Formato de etiquetas CSV

Usa el ID de la fila para identificar el archivo. También puedes usar archivo en lugar de id si el nombre es único en el lote.

id,nivel,etiqueta
U001,binario,Glaucoma
U002,trinario,Temprano

Binario admite Sano y Glaucoma. Trinario admite Sano, Temprano y Avanzado. Guarda el archivo en UTF-8 y usa comas.
